# Hardware — OmniDock

Esta carpeta almacena el diagrama esquemático de conexiones del prototipo OmniDock, integrando el microcontrolador ESP32 DevKit V1, la cámara ESP32-CAM S3, la fuente MB102 de 5V/3.3V, los 5 sensores infrarrojos FC-51, el lector biométrico AS608, el sensor magnético MC-38, el servomotor MG90S, el puente H L298N y el módulo de audio DFPlayer Mini.
